Privacy Policy

Last updated: 2026-11-25

emo-observer is a private tool used only by its operator. It is not offered to the public.

Google user data

  • What is accessed: only files that emo-observer itself creates in the operator's Google Drive (OAuth scope https://www.googleapis.com/auth/drive.file). It cannot see or read any other file.
  • How it is used: to upload, list, verify and download compressed archives of public blockchain data collected by the tool.
  • Storage: the OAuth refresh token is stored only on the operator's own server in a file readable by the service account alone.
  • Sharing: no Google user data is shared with, sold to, or transferred to any third party, and it is not used for advertising or to train models.
  • Revocation: access can be revoked at any time at myaccount.google.com/permissions; the archive files remain in the operator's Drive and can be deleted there.

emo-observer's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
